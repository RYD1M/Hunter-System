# Hunter-System

Offline habit tracker, single-file HTML/CSS/JS. Solo Leveling-style XP/rank progression from E-Rank to Monarch.

## Features
- XP and rank progression system
- Streak tracking with penalties for bad habits
- Deadline countdowns
- Stats, History, and Notes tabs
- Auto-recovery on data issues

## Usage
Open the HTML file in a browser. No install, no server, no dependencies.

## Notes
Two file variants exist differing in day-rollover behavior — `__1_` is the correct version with fixes for backup/restore and streak logic.
